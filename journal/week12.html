5.7

Method

The Wilcoxon signed rank test is analyzing ranks and the difference between two values. Before ranking, the difference between the paired bivariate observations will be calculated and we will eliminate any 0 differences. The differences are ranked based on the absolute value of the difference. There will be positive and negative ranks.

Assumptions

  1. The distribution of each \(D_i\) is symmetric
  2. The \(D_i\)s are mutually independent
  3. The \(D_i\)s have the same median
  4. The measurement scale of the \(D_i\)s is at least interval

Parametric equivalent (or proof that there is none)

The parametric equivalent of the Wilcoxon signed rank test is a paired t-test. If we do not meet the normality assumption for the paired t-test, we will use Wilcoxon signed rank.

Hypotheses

Two-tailed:

  • \(H_0\): \(M_d = M_0\)
  • \(H_A\): \(M_d \neq M_0\)

Left-tailed:

  • \(H_0\): \(M_d \leq M_0\)
  • \(H_A\): \(M_d > M_0\)

Right-tailed:

  • \(H_0\): \(M_d \geq M_0\)
  • \(H_A\): \(M_d < M_0\)

Rejection Region

Two-tailed:

  • Reject \(H_0\) if \(T^+\) or \(T\) is less than its \(\alpha/2\) quantile or greater than its \(1-\alpha/2\) quantile obtained from table A1

Left-tailed:

  • Reject \(H_0\) if \(T^+\) or \(T\) is less than its \(\alpha\) quantile from Table A12 for \(T^+\) or Table A1 for \(T\)

Right-tailed:

  • Reject \(H_0\) if \(T^+\) or \(T\) is greater than its \(\alpha\) quantile from Table A12 for \(T^+\) or Table A1 for \(T\)

Test Statistic and/or p-value

  • Test Statistic: Let \(R_i\) (the signed rank) be defined for each pair \((X_i, Y_i)\) as follows:

    \(R_i\) = the rank assigned to \((X_i, Y_i)\) if \(D_i = Y_i - X_i\) is positive \(R_i\) = the negative of the rank assigned to \((X_i, Y_i)\) if \(D_i\) is negative

    The test statistic is the sum of the positive signed ranks: \[ T^+ = \sum (R_i \text{ where } D_i \text{ is positive}) \] \[ T_0 = \text{min} (T_+, |T_-|) \text{ if two tailed, } T_0 = T_+ \text{ if left tailed, } T_0 = |T_-| \text{ if right tailed } \]

  • Lower quantiles of exact null distribution of \(T\) are in Table A12 where there are no ties and \(n\leq50\). Upper quantiles are found by \[ w_p = \frac{n(n+1)}{2} - w_{1-p} \]

    If there are many ties or if \(n > 50\), the normal approximation should be used. It uses the sum of all signed ranks (positive AND negative) and the test statistic mentioned above. If there are no ties, the test statistic equation can be simplified.

  • The p-value is obtained differently for the different tests:

    • Two-tailed: p-value = 2*(smaller of the one-tailed p values)
    • Left-tailed:

\[ P(Z \leq \frac{\sum_{i=1}^n R_i + 1}{\sqrt{\sum_{i=1}^n R_i^2}}) \]

  • Right-tailed:

\[ P(Z \geq \frac{\sum_{i=1}^n R_i + 1}{\sqrt{\sum_{i=1}^n R_i^2}}) \]

Confidence Interval for the Mean difference

Data

The data consists of n observations on the bivariate random variables. Compute the difference between the bivariate random variables: \(D_i = Y_i-X_i\) for each pair and arrange them in order from the smallest to the largest. Or, in a one sample situation, the data consists of \(D_1, D_2, ...\) arranged in order. We will find a confidence interval for the \(D_i\)s.

Assumptions

  1. The distribution of each \(D_i\) is symmetric
  2. The \(D_i\)s are mutually independent
  3. The \(D_i\)s have the same median
  4. The measurement scale of the \(D_i\)s is at least interval

Method/Approach

To obtain \(1-\alpha\) CI, obtain the \(\alpha/2\) quantile \(w_{\alpha/2}\) from Table A12. Note: If \(w_{\alpha/2}=0\) no CI may be obtained for that value of alpha. Then consider the \(n(n+1)/2\) possible averages \((D_i + D_j)/2\) for all \(i\) and \(j\), including \(i=j\), which is the average of \(D_i = D_i\). The \(w_{\alpha/2}\)th largest of these averages and the \(w_{\alpha/2}\)th smallest of these averages are the upper and lower bounds for the \(1-\alpha\) CI. Note: Only necessary to compute the averages near the largest and the smallest to obtain the CI.

5.8

Method

The Friedman test depends only on the ranks of the observations within each block, and is therefore considered a two-way analysis of variance (two-way ANOVA) on ranks. The data consists of \(b\) mutually independent \(k\)-variate random variables called \(b\) blocks. The random variable \(X_{ij}\) is in block \(i\) and associated with treatment \(j\). Rank 1 is assigned to smallest observed value, and so on up to rank \(k\) assigned to the largest observation in block \(i\). Ranks are assigned in all blocks. Use average ranks in case of ties. Calculate sum of ranks.

Assumptions

  1. The \(b\) \(k\)-variate random variables are mutually independent (the results in one block do not influence results in another block)
  2. Within each block the observations may be ranked according to some criterion of interest

Parametric equivalent (or proof that there is none)

The parametric equivalent of the Friedman test is two-way ANOVA. If two-way ANOVA assumptions are broken, Friedman will be used.

Hypotheses

  • \(H_0\): Each ranking of the random variables within a block is equally likely, meaning the treatments have identical effects
  • \(H_A\): At least one of the treatments tends to yield larger observed values than at least one other treatment

Rejection Region

Reject \(H_0\) if \(T_2\) exceeds the \(1-\alpha\) quantile of the F distribution given by Table A22 for \(k_1 = k-1\) and \(k_2 = (b-1)(k-1)\)

Note: The following method can be used for comparing individual treatments if the Friedman test results in the rejection of the null hypothesis. Treatments \(i\) and \(j\) are considered different if the following inequality is satisfied: \[ |R_j - R_i| > t_{1-\alpha/2} \left[ \frac{2(bA_1- \sum R_j^2}{(b-1)(k-1)} \right]^{\frac12} \]

Test Statistic and/or p-value

  • Test Statistic: The two-way ANOVA statistic computed on the ranks \(R(X_{ij})\) which simplifies to: \[ T_2 = \frac{(b-1)T_1}{b(k-1)-T_1} \] Note: equation for \(T_1\) can be found on page 370, if needed.

  • The exact distribution for \(T_1\) or \(T_2\) is difficult to find. Chi-squared distribution is the approximate distribution of \(T_1\) with \(k-1\) degrees of freedom. Since \(T_1\) is unreliable, the approximate quantiles given by F distribution in Table A22 is used with \(T_2\)

  • The p-value is estimated from Table A22.

Confidence Interval for the Mean difference

Data

The data consists of n observations on the bivariate random variables. Compute the difference between the bivariate random variables: \(D_i = Y_i-X_i\) for each pair and arrange them in order from the smallest to the largest. Or, in a one sample situation, the data consists of \(D_1, D_2, ...\) arranged in order. We will find a confidence interval for the \(D_i\)s.

Assumptions

  1. The distribution of each \(D_i\) is symmetric
  2. The \(D_i\)s are mutually independent
  3. The \(D_i\)s have the same median
  4. The measurement scale of the \(D_i\)s is at least interval

Method/Approach

To obtain \(1-\alpha\) CI, obtain the \(\alpha/2\) quantile \(w_{\alpha/2}\) from Table A12. Note: If \(w_{\alpha/2}=0\) no CI may be obtained for that value of alpha. Then consider the \(n(n+1)/2\) possible averages \((D_i + D_j)/2\) for all \(i\) and \(j\), including \(i=j\), which is the average of \(D_i = D_i\). The \(w_{\alpha/2}\)th largest of these averages and the \(w_{\alpha/2}\)th smallest of these averages are the upper and lower bounds for the \(1-\alpha\) CI. Note: Only necessary to compute the averages near the largest and the smallest to obtain the CI.

Method

The Quade test also tests the null hypothesis of equal treatment menas in a randomized block design, but it uses information about the range of blocks relative to each other and gives more weight to blocks exhibiting the larger range. It uses the rankings in the blocks like the Friedman test. Find the ranks within blocks just like the Friedman test, then use the original observations \(X_{ij}\) to assign ranks similarly to the Friedman test. The sample range within block \(i\) is the difference between the largest and smallest observations of that block. There are \(b\) sample ranges assigned to each block, rank 1 to the block with the smallest range, and so on. Lastly, the block rank \(Q_i\) is multiplied by the difference between the rank within block \(i\), and the average rank within block \((k+1)/2\) to get the product \(S_{ij}\), which represents the relative size of each observation within the block. It is adjusted to reflect relative significance of the block in which it appears.

Assumptions

The first two assumptions from the Friedman test hold. 3. The sample range may be determined wihtin each block so that the blocks may be ranked

Parametric equivalent (or proof that there is none)

The parametric equivalent of the Quade test is also two-way ANOVA, just like the Friedman test.

Hypotheses

Same as Friedman test.

Rejection Region

Reject \(H_0\) if \(T_3\) exceeds the \(1-\alpha\) quantile of the F distribution given by Table A22 for \(k_1 = k-1\) and \(k_2 = (b-1)(k-1)\)

Note: The following method can be used for comparing individual treatments if the Quade test results in the rejection of the null hypothesis. Treatments \(i\) and \(j\) are considered different if the following inequality is satisfied: \[ |S_i - S_j| > t_{1-\alpha/2} \left[ \frac{2b(A_2- B)}{(b-1)(k-1)} \right]^{\frac12} \]

Test Statistic and/or p-value

  • Test Statistic: First calculate \[ A_2 = \sum_{i=1}^b \sum_{j=1}^k S_{ij}^2 \]

    This can then be simplified if there are no ties. Next calculate \[ B = \frac1b \sum_{j=1}^k S_j^2 \] which is called the treatment sum of squares. Then the test statistic is: \[ T_3=\frac{(b-1)B}{A_2-B} \] Note: If \(A_2=B\), consider the point ot be in the critical region and calculate the p-value as \((1/k!)^{b-1}\)

  • The exact distribution for \(T_3\) is difficult to find, soo the approximate quantiles given by F distribution in Table A22 is used

  • The p-value is estimated from Table A22.

Alternative Method

The Page test for Ordered Alternatives is used with Spearman’s \(\rho\). In randomized complete block design, rho is used to test for \(k\) related samples against the alternative hypothesis of a specified ordering of the treatment effects. The correlation between Friedman within-block rankings and the ordering of the treatments as specified by \(H_1\) is used in a Page test. Page uses a simpler statistic because of the many inherent ties in the data. It is a monotonic function of Spearman’s \(\rho\) if there is no ties within blocks:

\[ T_4 = \sum_{j=1}^k jR_j = R_1 + 2R_2 + ... + kR_k \]

where \(R_j\) is the treatment rank sum from the Friedman test. Only large sample approximation will be considered. Reject \(H_0\) when \[ T_5 = \frac{T_4 -bk(k+1)^2/4}{[b(k^3-k)^2/144(k-1)]^{1/2}} \] exceeds the \(1-\alpha\) quantile from a standard normal distribution from Table A1.
