6.1

Method

The Kolmogorov Goodness of fit test is used on data consisting of a random sample of size n associated with some unknown distribution function F(x).

Assumptions

  1. The sample is a random sample

Parametric equivalent (or proof that there is none)

There is no direct parametric equivalent for the Kolmogorov Goodness of fit test.

Hypotheses

Two-tailed:

  • \(H_0\): \(F(x) = F^*(x)\) for all \(x\) from \(-\infty\) to \(+\infty\)
  • \(H_A\): \(F(x) \neq F^*(x)\) for at least one value of \(x\)

Left-tailed:

  • \(H_0\): \(F(x) \leq F^*(x)\) for all \(x\) from \(-\infty\) to \(+\infty\)
  • \(H_A\): \(F(x) > F^*(x)\) for at least one value of \(x\)

Right-tailed:

  • \(H_0\): \(F(x) \geq F^*(x)\) for all \(x\) from \(-\infty\) to \(+\infty\)
  • \(H_A\): \(F(x) < F^*(x)\) for at least one value of \(x\)

Rejection Region

Two-tailed:

  • Reject \(H_0\) if \(T\) exceeds the \(1-\alpha\) quantile from Table A13

Left-tailed:

  • Reject \(H_0\) if \(T^+\) or \(T\) is less than its \(\alpha\) quantile from Table A12 for \(T^+\) or Table A1 for \(T\)

Right-tailed:

  • Reject \(H_0\) if \(T^+\) or \(T\) is greater than its \(\alpha\) quantile from Table A12 for \(T^+\) or Table A1 for \(T\)

Test Statistic and/or p-value

  • Test Statistic: Let \(S(x)\) be the emperical distribution function based on the random sample. The test statistic is defined differently for the three different hypotheses. Let \(F^*(x)\) be a completely specified hypothesized distribution function.

    Two-tailed:

    • Let the test statistic \(T\) be the greatest (denoted by sup for supremum) vertical distance between \(S(x)\) and \(F^*(x)\).

    Left-tailed:

    • Denote this test statistic by \(T^+\) and let it equal the greatest vertical distance attained by \(F^*(x)\) above \(S(x)\).

    Right-tailed:

    • Denote this test statistic by \(T^-\) and let it equal the greatest vertical distance attained by \(S(x)\) above \(F^*(x)\).

  • Null distribution: When F(x) is continuous and the null hypothesis is true the exact distribution function of \(T^+\) and \(T^-\) is given by: (exact quantiles are found in A13 for \(n\leq 40\))

\[ G(x) = 1-x\sum_{j=0}^{[n(1-x)]} {n \choose j} (1-x-\frac{j}{n})^{n-j} (x+\frac{j}{n})^{j-1} \]

The asymptotic distribution function as \(n\to \infty\) of \(\sqrt{n}T^+\) and \(\sqrt{n}T^-\) is given by: (used when \(n>40\))

\[ H(x) = \lim_{n \to \infty } G \left(\frac{x}{\sqrt{n}}\right)=1-e^{-2x^2} \] The approximate distribution function of \(T\) is: \[ P(T\leq x)=[G(x)]^2 \]

  • The p-value is obtained differently for the different tests:
    • Two-tailed: p-value = 2*(the one-tailed p values)
    • One-tailed:

\[ t\sum_{j=0}^{[n(1-t)]} {n \choose j} (1-t-\frac{j}{n})^{n-j} (t+\frac{j}{n})^{j-1} \]

Confidence Band for the Population distribution function

Data

The data consists of a random sample of size n associated with some unknown distribution function F(x).

Assumptions

  1. The sample is a random sample
  2. For the confidence coefficient to be exact, the random variables should be continuous. If the random variables are discrete the confidence band is conservative; that is, the true but unknown confidence coefficient is greater than the stated one.

Method/Approach

Draw a graph of the emperical distribution function S(x) based on the random sample. To form a confidence band with a confidence coefficient \(1-\alpha\) find the \(1-\alpha\) quantile of the Kolmogorov test statistic from table A13 for the two-sided test and for the appropriate sample size n. Let \(w_{1-\alpha}\) denote that quantile. Draw a graph above S(x) a distance and call this second graph L(x). Then U(x) and L(x) form the upper and lower boundaries, respectively, of a \(1-\alpha\) confidence band that contains the unknown F(x) completely within its boundaries.

There’s no reason for U(x) to be drawn above 1.0 even though \(S(x) + w_{1-\alpha}\) might exceed 1.0, because we known that no distribution function ever exceeds 1.0. For the same reason L(x) should not extend below the horizontal axis.

Completed Homework Problem

  1. For the data in exercise 1, test the hypothesis that the distribution of times is uniform on the interval from 4 to 8 seconds. Note that such a distribution is given by: \(F^*(x) = 0\) for \(x<4\) \(F^*(x) = (x-4)/4\) for \((4\leq x<8)\) \(F^*(x) = 1\) for \(8\leq x\)
# data
times <- c(6.3, 4.2, 4.7, 6.0, 5.7)

# specify hypothesized CDF F*(x)
Fstar <- function(x) {
  ifelse(x < 4, 0,
         ifelse(x < 8, (x - 4) / 4, 1))
}

# KS goodness-of-fit test
dgof::ks.test(times, Fstar)

    One-sample Kolmogorov-Smirnov test

data:  times
D = 0.425, p-value = 0.2473
alternative hypothesis: two-sided

  • Hypotheses

    • \(H_0\): The distribution of race times follows a Uniform(4, 8) distribution.
    • \(H_1\): The distribution of race times does not follow a Uniform(4, 8) distribution.

  • Test Statistic and p-Value

    • \(D = 0.425\)

    • \(p = 0.2473\)

  • Rejection Region

    • Reject \(H_0\) if \(p < \alpha\); \(\alpha=0.05\)

  • Conclusion/Interpretation

    • Fail to Reject \(H_0\). There is sufficient evidence to suggest that the distribution of race times does not follow a Uniform(4, 8) distribution.

6.2

Method

The Lilliefors test for normality is a modified Kolmogorov test used to test the composite hypotheses of normality. The data consists of a random sample of size n associated with some unknown distribution function F(x). Compute the sample mean for use as an estimate of \(\mu\) and compute:

\[ s = \sqrt{\frac{1}{n-1} \sum_{i=1}^n (X_i-\bar{X})^2} \] as an estimate of \(\sigma\). Then compute the normalized sample values:

\[ Z_i = \frac{X_i-\bar{X}}{s} \text{ for } i=1, 2, ..., n \]

Assumptions

  1. The sample is a random sample

Parametric equivalent (or proof that there is none)

Hypotheses

  • \(H_0\): The random sample comes from a population with the normal distribution, with unknown mean and standard deviation
  • \(H_A\): The distribution function of the \(X_i\)s is nonnormal

Rejection Region

  • Reject \(H_0\) if \(T_1\) exceeds the \(1-\alpha\) quantile from Table A14

Test Statistic and/or p-value

  • Test Statistic: The usual two-sided Kolmogorov test statisitic - the maximum vertical distance between the empirical distribution function of the \(X_i\)s and the normal distribution function with mean \(\bar{X}\) and standard dev. \(s\). It can also be easily defined by:

\[ T_1 = \underset{x}{\text{sup}} | F^*(x) - S(x)| \]

  • Null distribution: The exact form of null distribution is unknown. It was approximately obtained by generating thousands of pseudo-random numbers on a computer, and estimating quantiles from the empirircal distribution function of the thousands of subsequent values of test statistic.

  • The p-value can be approximated from the quantiles in table A14.

Method

The Lilliefors test for the exponential distribution is a modified Lilliefors test. The data consists of a random sample of size n associated with some unknown distribution function, denoted by F(x). Compute the sample mean to use as an estimate for unknown parameter. For each \(X_i\), compute: \[ Z_i = X_i / \bar{X} \]

Assumptions

  1. The sample is a random sample

Parametric equivalent (or proof that there is none)

Hypotheses

  • \(H_0\): The random sample has the exponential distribution: \[F(x) = 1-e^{-x/t}, x>0\], or \[F(x) = 0, x<0\]

where \(t\) is an unknown parameter

  • \(H_A\): The distribution of X is not exponential

Rejection Region

  • Reject \(H_0\) if \(T_2\) exceeds the \(1-\alpha\) quantile from Table A15

Test Statistic and/or p-value

  • Test Statistic: The empirical distribution function S(x) based on Zs is plotted on a graph. On the same graph, \(F(x) = 1-e^{-x}\) is plotted for x>0. The max vertical distance between these two functions is:

\[ T_2 = \underset{x}{\text{sup}} | F^*(x) - S(x)| \]

  • Null distribution: The exact quantiles are in table A15.

  • The p-value can be approximated by interpolation in table A15.

Method

The Shapiro-Wilk test (W test) for normality is not a Kolmogorov-type test. It has good power in many situations when compared with many other tests of the composite hypothesis of normality (including chi-squared and Lilliefors). It can be used interchangabily with the Lilliefors test. The data consists of a random sample of size n associated with some unknown distribution function F(x).

Assumptions

  1. The sample is a random sample

Parametric equivalent (or proof that there is none)

Hypotheses

  • \(H_0\): F(x) is a normal distribution function with unspecified mean and variance

  • \(H_A\): F(x) is nonnormal

Rejection Region

  • Reject \(H_0\) if \(T_3\) is less than the \(\alpha\) quantile from Table A17

Test Statistic and/or p-value

  • Test Statistic: Compute denominator D of test statistic:

\[ D = \sum_{i=1}^n (X_i - \bar{X})^2 \] where \(\bar{X}\) is the sample mean. Order the sample from smallest to largest. and let \(X^{(i)}\) denote the ith order statistic. From table A16, for the observed sample size n, obtain coefficients \(a_1, ... a_k\) where \(k\) is approximately n/2. Test statistic is then:

\[ T_3 = \frac1D \left[ \sum_{i=1}^k a_i (X^{(n-i+1)} - X^{(i)}) \right]^2 \]

  • Null distribution: Quantiles of \(T_3\) are given in table A17.

  • The p-value can be approximated by interpolation in table A18.

shapiro.test(x)
