Chapter 1 Notes

1.1

  • Experiment: process of following a well defined set of rules (results of rules is not known prior to the experiment)
  • Events: the possible outcomes of one trial, several trials, or the entire experiment. A combination of events may also be an event in itself
  • Rule 1: If an experiment consists of \(n\) trials where each trial may result in one of \(k\) possible outcomes, there are \(k^n\) possible outcomes of the entire experiment
  • Rule 2: there are \(n!\) ways of arranging \(n\) distinguishable objects into a row
  • Rule 3: if a group of \(n\) objects is composed of \(n_1\) identical objects of type 1, \(n_2\) identical objects of type 2, …, \(n_r\) identical objects of type \(r\), the number of distinguishable arrangements into a row is

\[ \binom{n}{n_1, n_2, \ldots, n_r} = \frac{n!}{n_1! n_2! \cdots n_r!} \]

  • If a group of \(n\) objects is composed of \(k\) identical objects of one kind and the remaining \((n-k)\) objects are identical objects of a second kind, the number of distinguishable arrangements is

\[ \binom{n}{k} = \frac{n!}{k!(n-k)!} \]

  • Note: \(\binom{n}{k} = 0\) if \(k > n\)
  • Binomial coefficient = \(\binom{n}{k}\)
  • Binomial expansion:

\[ (x+y)^n = \sum_{i=0}^n \binom{n}{i} x^i y^{n-i} \]

1.2

  • Sample space: collection of all possible different outcomes of an experiment
  • Point in the sample space: possible outcome of experiment
  • Event: any set of points in the sample space
  • Sure event: an event that is certain to occur every time the experiment is performed
  • Mutually exclusive events: the occurrence of one event automatically excludes the possibility of the other event occurring at the same time
  • If points in one event are contained in another event, we say the first event is contained in the second event
  • Probability of A = \(P(A)\), probability that A does not occur = \(1 - P(A)\)
  • Joint events: probability of joint events \(P(AB)\)
  • Conditional probability:

\[ P(A|B) = \frac{P(AB)}{P(B)} \]

  • Two events are independent if

\[ P(AB) = P(A)P(B) \]

  • Two experiments are independent if for every event A associated with one experiment and every event B associated with the second experiment:

\[ P(AB) = P(A)P(B) \]

  • Similarly, mutually independent events are just \(P(ABC\ldots)\) (keep multiplying probabilities together)

1.3

  • Random variable: function that assigns real numbers to the points in a sample space
  • Discrete uniform distribution: let \(X\) be a random variable. The probability function is

\[ f(x) = \frac{1}{N}, \quad x = 1, 2, \ldots, N \]

  • Hypergeometric distribution: let \(X\) be a random variable. The probability function is

\[ f(x) = P(X = x) = \frac{\binom{A}{x}\binom{B}{k-x}}{\binom{A+B}{k}} \]

  • where \(0 \leq x \leq A\), \(0 \leq k-x \leq B\), and \(k \leq A+B\) with \(A,B,k \geq 0\)

1.4

  • Distribution function: describes all properties of a random variable
  • Quantiles: method used for summarizing a distribution
  • \(p\)th quantile of random variable \(X\): number \(x_p\) if

\[ P(X < x_p) \leq p \quad \text{and} \quad P(X > x_p) \leq 1-p \]

  • Expected value:

\[ E[u(X)] = \sum_x u(x) f(x) \]

  • Mean:

\[ \mu = E(X) = \sum_x x f(x) \]

  • Variance:

\[ \sigma^2 = E\big[(X - \mu)^2\big] \]

  • Covariance:

\[ \operatorname{Cov}(X_1, X_2) = E(X_1 X_2) - \mu_1 \mu_2 \]

  • Correlation coefficient:

\[ \rho = \frac{\operatorname{Cov}(X_1, X_2)}{\sigma_{X_1}\sigma_{X_2}} \]

  • Theorem 2: If \(X_1\) and \(X_2\) are independent random variables, \(\operatorname{Cov}(X_1, X_2)=0\)
  • Theorem 3: Let \(X_1, X_2, \ldots, X_n\) be random variables and \(Y=X_1+X_2+\cdots+X_n\). Then

\[ \operatorname{Var}(Y) = \sum_{i=1}^n \operatorname{Var}(X_i) + \sum_{i=1}^n \sum_{j=1}^n \operatorname{Cov}(X_i, X_j) \]

  • If \(X_1, X_2, \ldots, X_n\) are independent:

\[ \operatorname{Var}(Y) = \sum_{i=1}^n \operatorname{Var}(X_i) \]

  • Theorem 4: Binomial distribution \(P(X=k)\):

\[ P(X=k) = \binom{n}{k} p^k q^{n-k}, \quad E(X)=np, \quad \operatorname{Var}(X)=npq \]

  • Theorem 5: If \(X\) is the sum of \(n\) integers selected randomly without replacement from \(1\) to \(N\):

\[ E(X) = \frac{n(N+1)}{2}, \quad \operatorname{Var}(X) = \frac{n(N+1)(N-n)}{12} \]

1.5

  • Discrete random variable: if values correspond one-to-one with some or all positive integers
  • Distribution of discrete random variable = step function
  • Continuous random variable: \(X\) is continuous if

\[ P(X \leq x) = P(X < x) \quad \text{for all } x \]

  • Normal distribution (see pg. 55–56 in textbook)
  • Central limit theorem (pg. 56)
  • Chi-squared distribution: If \(X_1, X_2, \ldots, X_k\) are i.i.d. standard normal, then

\[ Y = X_1^2 + X_2^2 + \cdots + X_k^2 \]

follows a chi-squared distribution with \(k\) degrees of freedom.

Chapter 1 Summary

In chapter 1, we discuss counting rules. I recognized these rules as the rules for combinations, like n choose k. These rules allow us to determine the number of distinguishable arrangements of objects into a row. This can be calculated even if there are one or multiple identical objects present in a group. The total number of possible outcomes of each trial in an experiment can also be determined using counting rules.

Next, we looked at defining and describing experiments and events. We used probabilities to describe events associated with experiments. The probability that an event occurs or does not occur was discussed, along with the probability that an event occurred given that another event occurred, also known as the conditional probability. It was also essential to learn how to identify whether or not two events were independent of each other, which was done by determining if P(AB) = P(A)P(B), where A and B are events.

We then moved onto learning about random variables. Distributions like the discrete uniform distribution and the hypergeometric distribution rely on the probability function of X, where X is a random variable. Distribution functions allow us to view all the properties of a random variable since it shows us all the possible probabilities associated with a random variable. We then use quantiles to describe the overall behavior of a distribution function.

Expected values are used to calculate many different test statistics/statistical values. They are used to calculate the mean, interquartile range (IQR), standard deviation, variance, covariance, and correlation coefficient of random variables.

To conclude chapter 1, the following distributions were defined using probability functions/theorems: normal distribution and chi-squared distribution. Since I have learned and used those distributions in previous courses, I did not focus on this section.

Chapter 2 Notes

2.1

  • Population: collection of all elements under investigation
  • Convienience sample: collection of elements that are easiest to obtain
  • Sampled population VS. target population
  • Random sample: usually done without replacement (same element can’t appear more than once in the sample), a sequence of \(n\) independent and identically distributed random variables
  • Nominal scale: uses numbers to separate properties or elements into different classes/categories
  • Ordinal scale: measurements where only the comparisons “greater”, “less”, or “equal” between measurements are relevant
  • Interval scale: considers relative order according to ordinal scale and the size of the interval between measurements
  • Ratio scale: used when order, interval size, and ratio been two measurements are important
  • Statistic: function of several random variables
  • Order statistics: used when dealing with ordinal-type measurements; called the order statistic of rank \(k\), \(X^k\), is the statistic that takes as its value the \(k\)th smallest element \(x^k\) in each observation

2.2

  • Empirical Distribution Function (EDF): \(S(x)\) is a function of \(x\) which equals the fraction of \(X_i\)s that are less than or equal to \(x\) for each \(x, -\infty < x < \infty\)
  • Note: EDF is always a step function, each step is height \(1/n\), occurs only at sample values, also called a random function because it is used as an estimator. Observed value of EDF may be considered a population distribution function
  • \(p\)th sample quantile: a number \(Q_p\) that satisfies two conditions:
    1. fraction of the \(X_i\)s that are less than \(Q_p\) is <= \(p\)
    2. fraction of \(X_i\)s that exceed \(Q_p\) is <= \(1 - p\)
  • Equations for sample mean, sample variance, and sample standard deviation (pg. 83)
  • Point estimates of unknown population parameters
  • Interval estimator: estimates stated in interval form
  • Confidence coefficient: the probability that the interval estimator will contain the unknown population quantity
  • Unbiased estimator: \({\hat{\theta}}\) is unbiased estimator of population parameter \(\theta\) if \(E({\hat{\theta}}) = \theta\)
  • Standard deviation of estimator = standard error
  • Bootstrap: samples \(n\) values with replacement from the observations in the orginal random sample of size \(n\), always has the same number of observations as in the orginal random sample. Estimator \({\hat{\theta}}\) of interest is calculated for each bootstrap sample. The sample mean of this used to estimate the population mean of \({\hat{\theta}}\)
  • Survival function: \(P(x) = 1 - F(x)\), variable of interest is the lifetime of a person/animal/etc. The natural estimator of \(P(x)\) is the empirical survival function \(\hat{P}(x) = 1 - S(x)\) which is the relative frequency of the sample \(X_1, ..., X_n\) that exceeds \(x\) in value
  • Kaplan-Meier Estimator: \(\hat{P}(x) = 1\) for \(x < u_1 = \prod_{u_i \leq x} \hat{p_i}\) for \(x \geq u_1\), where the product is over all lifetimes \(u_i \leq x\). Decreasing step function
  • KME is the same as \(1 - S(x)\) if there are no losses, only deaths
  • Point estimation is always a nonparametric method because no knowledge of the form of the unknown distribution function is required in order to make the estimate

2.3

  • Alternative hypothesis: statement to prove, AKA research hypothesis
  • Null/test hypothesis
  • Test statistic: used to help make decision in hypothesis test
  • Decision rule: made in terms of the test statistic, helps decide whether to accept/reject null hypothesis
  • Simple hypothesis: if the assumption that the hypothesis is true leads to only one probability function defined on the sample space
  • Composite hypothesis: leads to two or more probability functions ^
  • Upper/lower tailed tests
  • One-tailed VS two-tailed tests
  • Critical region: set of all points in the sample space that result in the decision to reject null hypothesis
  • Type I error: error of rejecting a true null hypothesis
  • Type II error: error of accepting a false null hypothesis
  • Level of significance \(\alpha\): max probability of rejecting a true null hypothesis
  • Null distribution: of test statistic, probability distribution when the null hypothesis is assumed to be true
  • Power: denoted by \(1 - \beta\), probability of rejecting a false null hypothesis
  • P-value

2.4

  • Test should be unbiased, consistent, and more efficient in some sense than the other tests
  • Power function
  • Unbiased test: the probability of rejecting \(H_0\) when \(H_0\) is false is always greater than/equal to probability of rejecting \(H_0\) when \(H_0\) is true. The power is always at least as large as level of significance
  • Test w/ smaller sample size is said to be more efficient than other test, and its relative efficiency is greater than 1
  • Asymptotic relative efficiency (A.R.E.): pg 111-112
  • Conservative test: if actual level of significance is smaller than the stated level of significance

2.5

  • Parametric methods’ validity depends on knowing the population distribution function.
  • Nonparametric methods are robust for distribution assumptions on the population
  • Asymptotically distribution-free: as sample size gets larger, method becomes more robust
  • A method is nonparametric if it satisfies at least one of the following criteria:
    1. method may be used on data with a nominal scale of measurement
    2. method may be used on data with an ordinal scale of measurement
    3. may be used on data w/ ratio or interval scale, where distribution function of the random variable producing the data is either unspecified or specified except for an infinite number of unknown parameters

Chapter 2 Summary

In chapter 2, we shifted focus from counting rules and random variables to sampling, estimation, and hypothesis testing. We began by defining populations and samples. A sample can be random, where each observation is independent and identically distributed, or it can be biased. We also reviewed the following different types of measurement scales: nominal, ordinal, interval, and ratio. We saw how order statistics can be applied when analyzing ordered data.

Next, we explored estimation methods. The empirical distribution function (EDF) was introduced as a way to approximate the population distribution based on observed data. We then used concepts like sample mean, variance, and quantiles as point estimators of population parameters. We also learned about interval estimation, confidence coefficients, and unbiased estimators. The bootstrap method was also introduced as a resampling approach to approximate population quantities without requiring prior knowledge of the distribution. In survival analysis, the empirical survival function and the Kaplan-Meier estimator were discussed as nonparametric methods for estimating lifetime distributions.

We then studied hypothesis testing. This included defining null and alternative hypotheses, test statistics, and decision rules. Errors in hypothesis testing were categorized into Type I and Type II errors, with significance level (\(\alpha\)), power, and p-values helping us evaluate tests. We also discussed test properties such as unbiasedness, consistency, and efficiency. We also learned that the power function plays an important role in comparing tests.

Finally, we compared parametric and nonparametric methods. Parametric methods depend on knowing the population distribution. This is unlike nonparametric methods, which are more flexible and robust to distributional assumptions. Nonparametric tests can be applied to nominal, ordinal, interval, and ratio data.
