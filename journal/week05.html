4.1

Method 1

The Chi-squared Test for difference in probabilities with a 2x2 contingency table is used to test if the probability of an event is the same for both populations that the random samples are drawn from.

A random sample of \(n_1\) observations is drawn from one population (or before a treatment is applied) and each observation is classified into either class 1 or 2, the total number of classes being \(O_{11}\) and \(O_{12}\), where \(O_{11} + O_{12} = n_1\). A second random sample of \(n_2\) observations is drawn from a second population (or the first population after some treatment is applied) and the number of observations in class 1 or class 2 is \(O_{21}\) and \(O_{22}\), where \(O_{21} + O_{22} = n_2\). This data can be arranged into a 2x2 contingency table with the total number of observations denoted as \(N\).

Assumptions

  1. Each sample is a random sample
  2. The two samples are mutually independent
  3. Each observation may be categorized either into class 1 or class 2

Parametric equivalent (or proof that there is none)

The book does not specifically mention a parametric equivalent. However, a quick search on Google allowed me to find the two-proportion Z-test, which seems to be fairly similar to the two-tailed version of this test. More information on this test can be found through this link: https://en.wikipedia.org/wiki/Two-proportion_Z-test.

Hypotheses

  • \(H_0\): \(p_1 = p_2\) (two-tailed) | \(p_1 \geq p_2\) (left-tailed) | \(p_1 \leq p_2\) (right-tailed)
  • \(H_A\): \(p_1 \neq p_2\) (two-tailed) | \(p_1 < p_2\) (left-tailed) | \(p_1 > p_2\) (right-tailed)

where \(p_1\) is the probability that a randomly selected element will be in class 1 (in population 1) and \(p_2\) in population 2. Note: \(p_1\) and \(p_2\) do not have to be known explicitly.

Rejection Region

Two-tailed:

  • Reject \(H_0\) at the approximate level \(\alpha\) if \(T_1 <\) the \(\alpha/2\) quantile of a standard normal random variable \(Z\), or if \(T_1 > 1 - \alpha/2\) quantile of \(Z\) (\(Z\) is given in Table A1).

Left-tailed:

  • Reject \(H_0\) at the approximate level of \(\alpha\) if \(T_1 < \alpha\) quantile of \(Z\) found in Table A1.

Right-tailed:

  • Reject \(H_0\) at the approximate level of \(\alpha\) if \(T_1 > 1 - \alpha\) quantile of \(Z\) found in Table A1.

Test Statistic and/or p-value

  • Test Statistic: If any column total is zero, \(T_1 = 0\). Otherwise: \[ T_1 = \frac {\sqrt{N}(O_{11}O_{22}-O_{12}O_{21})}{\sqrt{n_1 n_2 C_1 C_2}} \] Note: for two-tailed hypotheses, \(T_1^2\) is often used over \(T_1\) as the test statistic. Then the rejection region is the upper tail of the chi-squared distribution with 1 degree of freedom (given in Table A2).

  • The null distribution of \(T_1\) is hard to calculate exactly due to all the different combinations of the contingency table. Thus, large sample approximation is used, which is the standard normal distribution (refer to Table A1).

  • The p-value is obtained differently for the different forms:

    • Two-tailed: p-value is twice the smaller of the probabilities that \(Z \leq\) or \(\geq\) the observed value of \(T_1\) (observed from Table A1)
    • Left-tailed: p-value is the probability that \(Z <\) observed value of \(T_1\)
    • Right-tailed: p-value is the probability that \(Z >\) observed value of \(T_1\)

Method 2

Fisher’s Exact Test is also used with contingency tables, but only those with random row totals, random column totals, or both. The \(N\) observations in the data are summarized in a 2x2 contingency table usually. This is similar to the Chi-squared test for difference in probabilities, except both of the row totals, \(r\) and \(N-r\), and both column totals, \(c\) and \(N-c\), are predetermined/fixed.

Assumptions

  1. Each observation is classified into exactly one cell.
  2. The row and column totals are fixed, not random.

Parametric equivalent (or proof that there is none)

Similarly to the Chi-squared test for differnce of probabilities, the book does not specifically mention a parametric equivalent. The two-proportion Z-test is fairly similar to the two-tailed version of this test. More information on this test can be found through this link: https://en.wikipedia.org/wiki/Two-proportion_Z-test.

Hypotheses

  • \(H_0\): \(p_1 = p_2\) (two-tailed) | \(p_1 \geq p_2\) (left-tailed) | \(p_1 \leq p_2\) (right-tailed)
  • \(H_A\): \(p_1 \neq p_2\) (two-tailed) | \(p_1 < p_2\) (left-tailed) | \(p_1 > p_2\) (right-tailed)

where \(p_1\) is the probability of an observation in row 1 being classified into column 1, and \(p_2\) is the probability of an observation in row 2 being classified into column 1.

Rejection Region

Two-tailed:

  • Reject \(H_0\) at the level of significance \(\alpha\) if the p-value is \(\leq \alpha\).

Left-tailed:

  • Reject \(H_0\) at the level of significance \(\alpha\) if \(P(T_2 \leq t_{obs}) \leq \alpha\)

Right-tailed:

  • Reject \(H_0\) at the level of significance \(\alpha\) if \(P(T_2 \geq t_{obs}) \leq \alpha\)

Test Statistic and/or p-value

  • Test Statistic: \(T_2\) is the number of observations in the cell row 1, column 1.

  • The exact distribution of \(T_2\) when \(H_0\) is true is given by the hypergeometric distribution: \[ P(T_2 = x) = \frac{\binom{r}{x} \binom{N-r}{c-x}}{\binom{N}{c}} \quad x = 0, 1, \ldots, \min(r,c) \] = 0 for all other values of x. For large sample approximation, use this equation, which is the standard normal distribution given in Table A1: \[ T_3 = \frac{x - \frac{rc}{N}}{\sqrt{\frac{rc(N-r)(N-c)}{N^2 (N-1)}}} \]

  • Let \(t_{obs}\) be the observed value of \(T_2\). The p-value is obtained differently for the different forms:

    • Two-tailed: p-value is twice the smaller of \(P(T_2 \leq t_{obs})\) or \(P(T_2 \geq t_{obs})\)
    • Left-tailed: p-value is \(P(T_2 \leq t_{obs})\)
    • Right-tailed: p-value is \(P(T_2 \geq t_{obs})\)

Method 3

The Mantel-Haenszel test is very similar to the Fisher’s Exact test for 2x2 contingency tables. The Mantel-Haenszel tests association between two binary variables while controlling for a third (stratification variable). A good example of this would be treatment vs. outcome, stratified by age group or study site. The data is summarized in several 2x2 contingency tables, each with nonrandom row and column totals. The number of tables is \(k \geq 2\), and the \(i\)th table is represented with the following table:

library(gt)

df <- data.frame(
  Row = c("Row 1", "Row 2", "Col Total"),
  `Col 1` = c("`$x_{i}$`", "`$c_{i} - x_{i}$`", "`$c_{i}$`"),
  `Col 2` = c("`$r_{i} - x_{i}$`", "`$N_{i} - r_{i} - c_{i} + x_{i}$`", "`$N_{i} - c_{i}$`"),
  `Row Total` = c("`$r_{i}$`", "`$N_{i} - r_{i}$`", "`$N_{i}$`")
)

df %>%
  gt() %>%
  fmt_markdown(columns = everything())
Row Col.1 Col.2 Row.Total
Row 1 $x_{i}$ $r_{i} - x_{i}$ $r_{i}$
Row 2 $c_{i} - x_{i}$ $N_{i} - r_{i} - c_{i} + x_{i}$ $N_{i} - r_{i}$
Col Total $c_{i}$ $N_{i} - c_{i}$ $N_{i}$

Assumptions

These are the same assumptions as the Fisher’s exact test: 1. Each observation is classified into exactly one cell. 2. The row and column totals are fixed, not random.

Parametric equivalent (or proof that there is none)

The parametric equivalent is a logistic regression with stratum fixed effects.

Hypotheses

Two-tailed:

  • \(H_0\): \(p_{1i} = p_{2i}\) for all \(i = 1, ..., k\)
  • \(H_A\): Either \(p_{1i} > p_{2i}\) for some \(i\), or \(p_{1i} < p_{2i}\) for some \(i\), but not both

Left-tailed:

  • \(H_0\): \(p_{1i} \geq p_{2i}\) for all \(i = 1, ..., k\)
  • \(H_A\): \(p_{1i} \leq p_{2i}\) for all \(i\), and \(p_{1i} < p_{2i}\) for some \(i\)

Right-tailed:

  • \(H_0\): \(p_{1i} \leq p_{2i}\) for all \(i = 1, ..., k\)
  • \(H_A\): \(p_{1i} \geq p_{2i}\) for all \(i\), and \(p_{1i} > p_{2i}\) for some \(i\)

where \(p_{1i}\) is the probability of an observation in row 1 being classified into column 1 in the \(i\)th contingency table, and \(p_{2i}\) is the probability of an observation in row 2 being classified into column 1 in the \(i\)th contingency table.

Rejection Region

Two-tailed:

  • Reject \(H_0\) at the level of significance \(\alpha\) if \(T_4\) exceeds \(z_{1-\alpha/2}\) or if \(T_4 < z_{\alpha/2}\), where \(z_p\) represents the \(p\)th quantile of the standard normal distribution (Table A1).

Left-tailed:

  • Reject \(H_0\) at \(\alpha\) if \(T_4 < z_\alpha\) from Table A1.

Right-tailed:

  • Reject \(H_0\) at \(\alpha\) if \(T_4 > z_{1-\alpha}\) from Table A1.

Test Statistic and/or p-value

  • Test Statistic: \[ T_4 = \frac{\sum x_i - \sum \frac{r_i c_i}{N_i}} {\sqrt{\sum \frac{r_i c_i(N_i -r_i)(N_i-c_i)} {N_i^2 (N_i-1)}}} \]

  • The null distribution of \(T_4\) when \(H_0\) is true is given by the standard normal distribution given in Table A1. Note: exact probabilities are improved by using a continuity correction (for left-tailed: add 0.5 to numerator of \(T_4\) before looking up the p-value in Table A1, for right-tailed subtract 0.5 from numerator before looking up p-value).

  • The p-value is obtained differently for the different forms:

    • Two-tailed: p-value is twice the probability of a standard normal random variable being < or > observed value of \(T_4\) (whichever is smaller)
    • Left-tailed: p-value is the probability of a standard normal random variable < observed value of \(T_4\)
    • Right-tailed: p-value is the probability of a standard normal random variable > observed value of \(T_4\)

4.2

Method 1

We move onto the Chi-squared test for differences in probabilities involving rxc contingency tables in 4.2. There are \(r\) populations in all, and one random sample is drawn from each population. Let \(n_i\) represent the number of observations in the \(i\)th sample from the \(i\)th population for \(1 \leq i \leq r\). Each observation in each sample can be classified into one of \(c\) different categories.

Let \(O_{ij}\) be the number of observations from the \(i\)th sample that fall into category \(j\), so: \(n_i = O_{i1} + O_{i2} + ... + O_{ic}\) for all \(i\). The data is arranged in a contingency table where the total number of observations from all samples is \(N = n_1 + n_2+ ... + n_r\).

Assumptions

  1. Each sample is a random sample
  2. The outcomes of the various samples are all mutually independent among samples
  3. Each observation may be categorized into exactly one of the \(c\) categories/classes

Parametric equivalent (or proof that there is none)

The parametric equivalent is logistic regression (for binary outcomes) or multinomial logistic regression (for >2 outcome categories).

Hypotheses

Let the probability of a randomly selected value from the \(i\)th population being classified in the \(j\)th class be denoted by \(p_{ij}\), for \(i = 1, 2, ..., r\) and \(j = 1, 2, ..., c\).

  • \(H_0\): All of the probabilities in the same column are equal to each other (i.e., \(p_{1j} = p-{2j} = ... = p_{rj}\), for all \(j\))
  • \(H_A\): At least two of the probabilities in the same column are not equal to each other (i.e., \(p_{ij} \neq p_{kj}\) for some pair \(i\) and \(k\))

Rejection Region

  • The critical region of approximate size \(\alpha\) corresponds to values of \(T\) larger than \(x_{1-\alpha}\), the \(1-\alpha\) quantile of a chi-squared random variable with \((r-1)(c-1)\) degrees of freedom obtained from Table A2.
  • Reject \(H_0\) if \(T > x_{1-\alpha}\).

Test Statistic and/or p-value

  • Test Statistic: \[ T = \sum_{i = 1}^r \sum_{j=1}^c \frac{(O_{ij} - E_{ij})^2}{E_{ij}} \] where \(E_{ij} = \frac {n_i C_j}{N}\).

  • The null distribution of \(T\) is approximately the chi-squared distribution with \((r-1)(c-1)\) degrees of freedom, whose quantiles are in Table A2.

  • The p-value is the probability of a chi-squared random variable with \((r-1)(c-1)\) degrees of freedom exceeding the observed value of \(T\), which can also be found in Table A2.

Method 2

The Chi-squared test for independence is performed to see whether or not the rows and columns of an rxc contingency table represent two independent classification schemes.

A random sample of size \(N\) is obtained. The observations can be classified according to two different criteria. Let \(O_{ij\) be the number of observations associated with row \(i\) and column \(j\) simultaneously. The total number of observations in row \(i\) is denoted as \(R_i\) and in column \(j\) by \(C_j\).

Assumptions

  1. The sample of \(N\) observations is a random sample. (Each observation has the same probability as every other observation of being classified in row \(i\) column \(j\), independently from the other observations)
  2. Each observation may be classified into exactly one of \(r\) different categories according to one criterion and into exactly one of \(c\) different categories according to a second criterion.

Parametric equivalent (or proof that there is none)

The parametric equivalent is log-linear models or logistic regression (in the 2×2 case).

Hypotheses

  • \(H_0\): The event “an observation is in row \(i\)” is independent of the event “that same observation is in column \(j\)”, for all \(i\) and \(j\). AKA, P(row \(i\), column \(j\)) = P(row \(i\)) * P(column \(j\)), for all \(i\) and \(j\)
  • \(H_A\): P(row \(i\), column \(j\)) \(\neq\) P(row \(i\)) * P(column \(j\)), for some \(i\) and \(j\)

Rejection Region

  • Reject \(H_0\) if \(T > x_{1-\alpha}\) quantile of a chi-squared random variable with \((r-1)(c-1)\) degrees of freedom (obtained from Table A2).

Test Statistic and/or p-value

  • Test Statistic: \[ T = \sum_{i = 1}^r \sum_{j=1}^c \frac{(O_{ij} - E_{ij})^2}{E_{ij}} \] where \(E_{ij} = \frac {n_i C_j}{N}\). (Identical to previous method)

  • The null distribution of \(T\) is approximately the chi-squared distribution with \((r-1)(c-1)\) degrees of freedom, whose quantiles are in Table A2.

  • The p-value is the probability of a chi-squared random variable with \((r-1)(c-1)\) degrees of freedom exceeding the observed value of \(T\), which can also be found in Table A2.

Method 3

The Chi-squared test with fixed marginal totals is similar to the previous methods, except the row and column totals are determined beforehand, and therefore are fixed, not random.

The row and column totals are denoted by \(n_i\) and \(c_j\) to emphasize that they are not random. The total number of observations is \(N\).

Assumptions

  1. Each observation is classified into exactly one cell
  2. The observations are on a random sample
  3. The row and column totals are given, not random.

Parametric equivalent (or proof that there is none)

There is not a parametric equivalent specifically listed because the fixed margins assumption is conditional. However, Fisher’s exact test’s underlying distribution, the hypergeometric distribution, is the exact parametric equivalent in this case. You could probably used conditional logistic regression when the margins are fixed by design.

Hypotheses

Let the probability of a randomly selected value from the \(i\)th population being classified in the \(j\)th class be denoted by \(p_{ij}\), for \(i = 1, 2, ..., r\) and \(j = 1, 2, ..., c\).

  • \(H_0\): All of the probabilities in the same column are equal to each other (i.e., \(p_{1j} = p-{2j} = ... = p_{rj}\), for all \(j\))
  • \(H_A\): At least two of the probabilities in the same column are not equal to each other (i.e., \(p_{ij} \neq p_{kj}\) for some pair \(i\) and \(k\))

OR

  • \(H_0\): The event “an observation is in row \(i\)” is independent of the event “that same observation is in column \(j\)”, for all \(i\) and \(j\). AKA, P(row \(i\), column \(j\)) = P(row \(i\)) * P(column \(j\)), for all \(i\) and \(j\)
  • \(H_A\): P(row \(i\), column \(j\)) \(\neq\) P(row \(i\)) * P(column \(j\)), for some \(i\) and \(j\)

(can be tailored to fit each problem)

Rejection Region

  • The critical region of approximate size \(\alpha\) corresponds to values of \(T\) larger than \(x_{1-\alpha}\), the \(1-\alpha\) quantile of a chi-squared random variable with \((r-1)(c-1)\) degrees of freedom obtained from Table A2.
  • Reject \(H_0\) if \(T > x_{1-\alpha}\).

Test Statistic and/or p-value

  • Test Statistic: \[ T = \sum_{i = 1}^r \sum_{j=1}^c \frac{(O_{ij} - E_{ij})^2}{E_{ij}} \] where \(E_{ij} = \frac {n_i C_j}{N}\). (same as other methods)

  • The null distribution of \(T\) is approximately the chi-squared distribution with \((r-1)(c-1)\) degrees of freedom, whose quantiles are in Table A2.

  • The p-value is the probability of a chi-squared random variable with \((r-1)(c-1)\) degrees of freedom exceeding the observed value of \(T\), which can also be found in Table A2.

4.3

Method

The Median Test examines whether several samples came from populations having the same median. It is basically a special application of the chi-squared test with fixed marginal totals.

From the \(c\) populations, a random sample size \(n_i\) where \(i = 1, 2,..., c\) is obtained. Then, the combined sample median, or grand median, is determined. Let \(O_{1i}\) be the number of observations in the \(i\)th sample that exceed grand median (AKA \(a\) in contingency table). Let \(O_{2i}\) be the number of observations in the \(i\)th sample that are \(\leq\) grand median (AKA \(b\) in contingency table). Arrange the frequency counts into a 2xc contingency table.

Assumptions

  1. Each sample is a random sample.
  2. The samples are independent of each other
  3. The measurement scale is at least ordinal
  4. If all populations have the same median, all populations have the same probability \(p\) of an observation exceeding the grand median

Parametric equivalent (or proof that there is none)

The parametric equivalents for the median test are the two-sample test (for comparing 2 medians/means) and one-way ANOVA (for comparing \(k\) medians/means).

Hypotheses

  • \(H_0\): All \(c\) populations have the same medians
  • \(H_A\): At least two of the populations have different medians

Rejection Region

  • Critical region of approximate size \(\alpha\) corresponds to values of \(T > x_{1-\alpha}\), the \(1-\alpha\) quantile of a chi-squared random variable with \((c-1)\) degrees of freedom obtained from Table A2.
  • Reject \(H_0\) if \(T > x_{1-\alpha}\).
  • Note: if \(H_0\) is rejected, pairwise multiple comparisons may be made between populations by using the median test repeatedly on 2x2 contingency tables. In each comparison, the median is found and the number above/below that median is used in the 2x2 contingency table. This does distrot the true level of significance of all tests but the first.

Test Statistic and/or p-value

  • Test Statistic (rearranged from previous section, note that \(O_{2i} = n_i - O_{1i}\) in the special case of two rows): \[ T = \frac {N^2}{ab} \sum_{i=1}^c \frac{(O_{1i} - \frac{n_i a}{N})^2}{n_i} \]

  • If \(a\) is approximately equal to \(b\), the following simplification can be used, and is exact if \(a=b\), approximate otherwise: \[ T = \sum_{i = 1}^c \frac{(O_{1i}-O_{2i})^2}{n_i} \]

  • The null distribution of \(T\) is approximately the chi-squared distribution with \((c-1)\) degrees of freedom. (difficult to tabulate the exact distribution of \(T\))

  • The p-value is approximately the probability of a chi-squared random variable with \((c-1)\) degrees of freedom exceeding the observed value of \(T\), which can be found in Table A2.

R function

R function for median test (obtained from https://www.statology.org/moods-median-test-r/)

median_test(response~group, data)

where response is a vector of response values, group is a vector of grouping values, and data is a data frame containing the response and group vectors.

producers <- c(6, 3, 1, 14, 8, 9, 12, 1, 3, 2, 1, 7)   
nonproducers <- c(6, 2, 1, 1, 3, 1, 2, 4, 8, 1, 2) 

# put into a data frame
df <- data.frame(
  bids = c(producers, nonproducers),
  group = factor(c(rep("Producer", length(producers)),
                   rep("Nonproducer", length(nonproducers))))
)

median_test(bids ~ group, data = df, distribution = "exact")

    Exact Two-Sample Brown-Mood Median Test

data:  bids by group (Nonproducer, Producer)
Z = -1.0911, p-value = 0.4003
alternative hypothesis: true mu is not equal to 0

Hypotheses

  • \(H_0\): The two groups (producer and nonproducers) have the same median number of bids
  • \(H_A\): At least one of the groups has a different median number of bids

Test Statistic and p-Value

  • \(T = -1.0911\)
  • \(p = 0.4003\)

Rejection Region

  • Reject \(H_0\) if \(p < \alpha\); \(\alpha=0.05\).

Conclusion/Interpretation

  • Fail to reject \(H_0\).

  • There is not sufficient evidence to suggest that the leases that eventually became producers of oil have the same medium number of bids as the leases that never produced oil.
