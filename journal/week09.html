5.4

Method

Spearman’s rho is a measure of correlation denoted by \(\rho\). It is calculated the same as Pearson’s \(r\) computed on the ranks and average ranks. The Spearman rank correlation coefficient is often used to test for independence between two random variables.

Parametric equivalent (or proof that there is none)

The parametric equivalent of Spearman rank correlation coefficient test is the Pearson correlation test for linear relationships. It assumes normality in the data without ranking them.

Hypotheses

Two-tailed:

  • \(H_0\): The \(X_i\) and \(Y_i\) are mutually independent
  • \(H_A\): Either, a) there is a tendency for the larger values of X to be paired with the larger values of Y, or b) there is a tendency for the smaller values of X to be paired with the larger values of Y

Left-tailed (for negative correlation):

  • \(H_0\): The \(X_i\) and \(Y_i\) are mutually independent
  • \(H_A\): There is a tendency for the smaller values of X to be paired with the larger values of Y, and vise versa

Right-tailed (for positive correlation):

  • \(H_0\): The \(X_i\) and \(Y_i\) are mutually independent
  • \(H_A\): There is a tendency for the larger values of X to be paired with the larger values of Y

Rejection Region

Two-tailed:

  • Reject \(H_0\) if the absolute value of \(\rho\) is greater than its \(1-\alpha/2\) quantile obtained from Table A10.

Left-tailed:

  • Reject \(H_0\) if \(\rho < -w_{1-\alpha}\) found in Table A10

Right-tailed:

  • Reject \(H_0\) if \(\rho > -w_{1-\alpha}\) found in Table A10

Test Statistic and/or p-value

  • Test Statistic: Pearson’s \(r\) computed on the ranks and average ranks: \[ \rho = \frac{\sum_{i=1}^n R(X_i)R(Y_i)-n(\frac{n+1}{2})^2}{(\sum_{i=1}^n R(X_i)^2-n(\frac{n+1}{2})^2)^{\frac{1}{2}}(\sum_{i=1}^n R(Y_i)^2 -n(\frac{n+1}{2})^2)^{\frac{1}{2}}} \]

  • Exact quantiles of \(\rho\) when X and Y are independent are given in Table A10 for \(n \leq 30\) and no ties. For larger n, or many ties, the pth quantile of \(\rho\) is given approximately by: \[ w_p = \frac{z_p}{\sqrt{n-1}} \]

  • The p-value is obtained differently for the different tests:

    • Two-tailed: using table A1

\[ 2*P(Z \geq |\rho| \sqrt{n-1}) \]

  • Left-tailed:

\[ P(Z \leq |\rho| \sqrt{n-1}) \]

  • Right-tailed:

\[ P(Z \geq |\rho| \sqrt{n-1}) \]

R function

R function for Spearman rank correlation coefficient test (obtained from https://www.rdocumentation.org/packages/stats/versions/3.6.2/topics/cor)

cor(x, y, method = “spearman”)

Method

Kendall’s tau \(\tau\) can be used as a test statistic to test the null hypothesis of independence between X and Y, with possible one-tailed or two-tailed alternatives (similarly described with Spearman’s rho).

Parametric equivalent (or proof that there is none)

The parametric equivalent of Kendall’s tau test is the Pearson correlation test (again, but with the distinction of using tau instead of rho). It assumes normality in the data without relying on rank coordinance.

Hypotheses

Two-tailed:

  • \(H_0\): X and Y are mutually independent
  • \(H_A\): Pairs of observations either tend to be concordant, or tend to be discordant

Left-tailed (for negative correlation):

  • \(H_0\): X and Y are mutually independent
  • \(H_A\): Pairs of observations either tend to be discordant

Right-tailed (for positive correlation):

  • \(H_0\): X and Y are mutually independent
  • \(H_A\): Pairs of observations either tend to be concordant

Rejection Region

Two-tailed:

  • Reject \(H_0\) if T or \(\tau\) is less than its \(\alpha/2\) quantile or greater than its \(1-\alpha/2\) quantile in the null distribution

Left-tailed:

  • Reject \(H_0\) if T or \(\tau\) is less than its \(\alpha\) quantile in the null distribution

Right-tailed:

  • Reject \(H_0\) if T or \(\tau\) is greater than its \(1-\alpha/2\) quantile in the null distribution

Test Statistic and/or p-value

  • Test Statistic: Kendall’s tau, where \(N_c\) = the number of concordant pairs of observations out of the total \(n \choose r\) total possible pairs, and \(N_d\) = total number of discordant pairs of observations: \[ \tau = T = N_c -N_d \]

  • Exact upper quantiles of \(\tau\) and T when X and Y are independent are given in Table A11 for \(n \leq 60\) and no ties. Lower quantiles for are the negative of the upper quantiles in the table. For larger n or many ties, the pth quantile is given by: \[ w_p = z_p \frac{\sqrt{2(2n+5)}}{3\sqrt{n(n-1)}} \] the pth quantile of T is given by:

\[ w_p = z_p \sqrt{n(n-1)(2n+5)/18} \]

  • The p-value is obtained differently for the different tests:
    • Two-tailed: left and right tailed p values
    • Left-tailed:

\[ P(Z \leq \frac{(T+1)\sqrt{18}}{\sqrt{n(n-1)(2n+5)}}) \]

  • Right-tailed:

\[ P(Z \geq \frac{(T-1)\sqrt{18}}{\sqrt{n(n-1)(2n+5)}}) \]

R function

R function for Kendall’s tau test (obtained from https://www.rdocumentation.org/packages/stats/versions/3.6.2/topics/cor)

cor.test(x, y, method = “kendall”)

Method

The Daniels test for trend is done by using Spearman’s rho to test for trend by pairing measurements called \(X_i\) with the time/order at which measurements were taken.

Parametric equivalent (or proof that there is none)

There is no specific parametric equivalent for this test. However, using simple linear regression or Pearson’s correlation coefficient test between the \(X_i\) and time might be able to yield similar results.

Assumptions

  1. The \(X_i\)s are mutually independent

Hypotheses

  • \(H_0\): The \(X_i\)s are identically distributed
  • \(H_A\): the distribution of the \(X_i\)s is related to time so that as time goes on, the X measurements tend to become smaller/larger.

Method

The Jonckheere-Terpstra test use either Kendall’s tau or Spearman’s rho in the case of several independent samples to see if all samples came from the same distribution.

Parametric equivalent (or proof that there is none)

There is no direct parametric equivalent for this test.

Hypotheses

  • \(H_0\): \(F_1(x) = F_2(x) =...=F_k(x)\)
  • \(H_A\): The distributions differ in a specified direction with at least one inequality: \(F_1(x) \geq F_2(x) \geq...\geq F_k(x)\), also written as \(E(Y_1) \leq E(Y_2) \leq ... \leq E(Y_k)\), where \(Y_i\) represent a random variable with the distribution function \(F_i(x)\).

Note: the same data setup and null hypothesis as in the Kruskall-Wallis test. However, using rho or tau is sensitive against only the ordering specified in the \(H_1\) given above, while Kruskall-Wallis is sensitive to any differences in means.

Method

Kendall’s Partial correlation coefficient is used to measure the correlation between two random variables, under the condition that the indirect influence due to other random variables is somehow eliminated/does not exist. An estimate of this partial correlation coefficient between (for example) \(X_1\) and \(X_2\), while the indirect correlation due to \(X_3, X_4, ..., X_n\) is eliminated, is denoted by \(r_{12.34...n}\) (Pearson’s r) or \(\tau_{12.34...n}\).

When \(n=3\), the partial correlation may be estimated by Pearson’s partial correlation coefficient: \[ r_{12.3} = \frac{r_{12} - r_{13}r_{23}}{\sqrt{(1-r_{13}^2)(1-r_{23}^2)}} \]

where \(r_{ij}\) is Pearson’s r computed between \(X_i\) and \(X_j\), and by Kendall’s partial correlation coefficient:

\[ \tau_{12.3} = \frac{\tau_{12} - \tau_{13}\tau_{23}}{\sqrt{(1-\tau_{13}^2)(1-\tau_{23}^2)}} \]

where \(\tau_{ij}\) is Kendalls’s tau computed between \(X_i\) and \(X_j\).

Completed Homework Problem

  1. A husband and wife who go bowling together kept their scores for 10 lines to see if there was a correlation between their scores. The scores can be seen below.
  1. Compute \(\rho\)
  2. Compute \(\tau\)
  3. Test the hypothesis of independence using a two-tailed test based on \(\rho\)
  4. Do the same from part c for \(\tau\)
husband <- c(147, 158, 131, 142, 183, 151, 196, 129, 155, 158)
wife <- c(122, 128, 125, 123, 115, 120, 108, 143, 124, 123)

#compute rho, part a
cor(husband, wife, method = "spearman")

#compute tau, part b
cor(husband, wife, method = "kendall")

#part c
cor.test(husband, wife, method = "spearman", exact = FALSE)

Part C Hypotheses

  • \(H_0\): The \(X_i\) and \(Y_i\) are mutually independent, where X = husband’s scores and Y = wife’s scores
  • \(H_A\): Either, a) there is a tendency for the larger values of X to be paired with the larger values of Y, or b) there is a tendency for the smaller values of X to be paired with the larger values of Y

Test Statistic and p-Value

  • \(T = 266.11\)
  • \(p = 0.05961\)

Rejection Region

  • Reject \(H_0\) if \(p < \alpha\); \(\alpha=0.05\).

Conclusion/Interpretation

  • Fail to Reject \(H_0\).There is not sufficient evidence to suggest that there is a monotonic association between the husband’s and wife’s bowling scores.

Part D Hypotheses

  • \(H_0\): X and Y are mutually independent, where X = husband’s scores and Y = wife’s scores
  • \(H_A\): Pairs of observations either tend to be concordant, or tend to be discordant

Test Statistic and p-Value

  • \(T = -2.0737\)
  • \(p = 0.03811\)

Rejection Region

  • Reject \(H_0\) if \(p < \alpha\); \(\alpha=0.05\).

Conclusion/Interpretation

  • Reject \(H_0\). There is sufficient evidence to suggest that there is a negative association between X and Y. Pairs tend to be discordant, meaning that when the husband’s score is relatively high, the wife’s score tends to be relatively low, and vice versa.
