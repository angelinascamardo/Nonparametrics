3.1

Method

The binomial test is used when a sample contains the outcomes of \(n\) independent trials. Each outcome can either be present in “class 1” or “class 2”, but cannot be present in both.

Assumptions

The \(n\) trials in the experiment must be independent. Each trial has a probability \(p\) which results in the outcome “class 1”, where \(p\) is the same for all \(n\) trials.

Parametric equivalent (or proof that there is none)

Since the binomial test assumes the data follows a binomial distribution, there is no parametric equivalent. The book states that the binomial test is often considered the most powerful test, and therefore it is claimed to be both parametric and nonparametric.

Hypotheses

  • \(H_0\): \(p = p^*\) for two-tailed, \(p \geq p^*\) for left-tailed, \(p \leq p^*\) for right-tailed
  • \(H_A\): \(p \neq p^*\) for two tailed, \(p < p^*\) for left-tailed, \(p > p^*\) for right-tailed

where \(p^*\) is some specified probability and \(0 \leq p^* \leq 1\).

Rejection Region

Two-tailed:

  • Using Table A3 (from back of book) - find the values for \(t_1\) and \(t_2\) such that: \[ P(Y \leq t_1) = \alpha_1 \] \[ P(Y \leq t_2) = 1 - \alpha_2 \] where \(Y\) is the binomial random variable with parameters \(p*\) and \(n\), \(\alpha_1\) is the size of the lower tail, and \(\alpha_2\) is the size of the upper tail.
  • Reject \(H_0\) if \(T \leq t_1\) or if \(T > t_2\).

Left-tailed:

  • Using Table A3 (from back of book) - find the value for \(t\) such that: \[ P(Y \leq t) = \alpha \]
  • Reject \(H_0\) if \(T \leq t\).

Right-tailed:

  • Using Table A3 (from back of book) - find the value for \(t\) such that: \[ P(Y \leq t) = 1 - \alpha \]
  • Reject \(H_0\) if \(T > t\).

Test Statistic and/or p-value

  • Test Statistic: \(T = O_1\), where \(T\) is the number of times the outcome is “class 1”, and \(O_1\) is the number of observations in “class 1”.
  • Null distribution is used. The null distribution of \(T\) is the binomial distribution with parameters \(p = p*\) and \(n=\) the sample size. Normal approximation is used for other values of \(n\) and \(p\) (i.e. \(n>20\) & select \(p\) values).
  • The p-value is obtained differently for the different forms:
    • Two-tailed: p-value is twice the smaller of the probabilities that \(Y \leq\) or \(\geq\) the observed value of \(T\)
    • Left-tailed: p-value is the probability that $Y $ observed value of \(T\)
    • Right-tailed: p-value is the probability that \(Y \geq\) observed value of \(T\)

R function

R function for binomial test (obtained from https://www.rdocumentation.org/packages/stats/versions/3.6.2/topics/binom.test):

binom.test(x, n, p = 0.5, alternative = c(“two.sided”, “less”, “greater”), conf.level = 0.95)

where \(x\) = number of successes, or a vector of length 2 giving the numbers of successes and failures, respectively; \(n\) = number of trials; and \(p\) = hypothesized probability of success. Alternative denotes whether the test is two-tailed, left-tailed, or right-tailed. Conf.level is the confidence level, usually 95%.

Confidence Interval

Data

A sample of observations on \(n\) independent trials is examined and the number \(Y\) of times the specified event occurs is noted.

Assumptions

  1. The \(n\) trials are mutually independent.
  2. The probability \(p\) of the specified event occurring remains constant from one trial to the next.

Approach

Approach A:

  • For \(n \leq 30\) and confidence coefficients of 0.90, 0.95, or 0.99, use Table A4.

Approach B:

  • For \(n > 30\) or confidence coefficients not covered in Table A4, use the normal approximation: \[ L = \frac Yn -z_{1-\alpha/2} \sqrt{Y(n-Y)/n^3} \] and \[ U = \frac Yn +z_{1-\alpha/2} \sqrt{Y(n-Y)/n^3} \]

where \(z_{1-\alpha/2}\) is the quantile of a normally distributed random variable obtained from Table A1. The confidence coefficient is approximately \(1-\alpha\).

  1. It is known that 20% of a certain species of insect exhibit a particular characteristic A. Eighteen insects of that species are obtained from an unusual environment, and none of these have characteristic A. Is it reasonable to assume that insects from that environment have the same probability of 0.20 that the species in general has? Use a two-tailed test.
binom.test(0, 18, p = 0.2,

3.2

Method

The quantile test is a variation of the binomial test. It is used to test hypotheses that concern the quantiles of a random variable.

Assumptions

The \(X_i\)s (i.e. \(X_1, X_2, ..., X_n\)) are a random sample (independent and identically distributed random variables). The measurement scale of the \(X_i\)s must be at least ordinal.

Parametric equivalent (or proof that there is none)

I obtained this information from these notes taken on this textbook: https://people.stat.sc.edu/hitchcock/notes518fall13sec32filledin.pdf

The quantile test about the median is testing the same thing as the t-test is about the mean. The quantile test is more efficient than the t-test when the population distribution is double exponential, or has heavy tails. Also, when considering the fact that the one sample t-test requires the data to be normal, the quantile test is more applicable and therefore preferred when it comes to nonparametric ordering statistics. However, the one sample t-test can be considered as the parametric equivalent to the nonparametric quantile test.

Hypotheses

  • \(H_0\): The \(p^*\)th population quantile is \(x^*\) (two-tailed) | The \(p^*\)th population quantile is no greater than \(x*\) (left-tailed) | The \(p^*\)th population quantile is at least as great as \(x^*\) (right-tailed)
  • \(H_A\): \(x^*\) is not the The \(p^*\)th population quantile (two-tailed) | The \(p^*\) population quantile is greater than \(x^*\) (left-tailed) | The \(p^*\) population quantile is less than \(x^*\) (right-tailed)

In other words,

  • \(H_0\): \(P(X \leq x^*) \geq p^*\) and \(P(X < x^*) \leq p^*\) (two-tailed) | \(P(X \leq x^*) \geq p^*\) (left-tailed) | \(P(X < x^*) \leq p^*\) (right-tailed)
  • \(H_1\): \(P(X \leq x^*) < p^*\) (left-tailed) | \(P(X < x^*) > p^*\) (right-tailed) | (two-tailed is either or)

where \(x^*\) and \(p^*\) are some specified numbers and \(0 < p^* < 1\).

Rejection Region

Two-tailed:

  • Using Table A3 (from back of book) - find the values for \(t_1\) and \(t_2\) such that: \[ P(Y \leq t_1) = \alpha_1 \] \[ P(Y \leq t_2) = 1 - \alpha_2 \] where \(Y\) has the binomial distribution with parameters \(p^*\) and \(n\), \(\alpha_1\) is the size of the lower tail, and \(\alpha_2\) is the size of the upper tail. The level of significance is \(\alpha_1 + \alpha_2\).
  • Reject \(H_0\) if \(T_1 \leq t_1\) or if \(T_2 > t_2\).

Left-tailed:

  • Using Table A3 (from back of book) - find the value for \(t_1\) such that: \[ P(Y \leq t_1) = \alpha \]
  • Reject \(H_0\) if \(T_1 \leq t_1\).

Right-tailed:

  • Using Table A3 (from back of book) - find the value for \(t_2\) such that: \[ P(Y \leq t_2) = 1 - \alpha \] OR \[ P(Y > t_2) = \alpha \]
  • Reject \(H_0\) if \(T_2 > t_2\).

Test Statistic and/or p-value

  • Test Statistic: \(T_1\) and \(T_2\), where \(T_1\) is the number of observations \(\leq x^*\) and \(T_2\) is the number of observations \(< x^*\). Then, \(T_1 = T_2\) if none of the numbers in the data set exactly equal \(x^*\); otherwise, \(T_1 > T_2\).
  • Null distribution is used. The null distribution of \(T_1\) and \(T_2\) is the binomial distribution with parameters \(p = p^*\) and \(n=\) the sample size. Normal approximation is used for other values of \(n\) and \(p\) (i.e. \(n>20\) & select \(p\) values).
  • The p-value is obtained differently for the different forms:
    • Two-tailed: p-value is twice the smaller of the probabilities that \(Y \leq\) or \(\geq\) the observed value of \(T_1\) or \(\geq\) the observed value of \(T_2\)
    • Left-tailed: p-value is the probability that \(Y \leq\) observed value of \(T_1\)
    • Right-tailed: p-value is the probability that \(Y \geq\) observed value of \(T_2\)

R function

R function for quantile test (obtained from https://people.stat.sc.edu/hitchcock/Rexamples518section3_2.txt):

Note: R has no built in quantile test function, so I am using this function created by a professor that made notes similar to the textbook I am learning from.

quantile.test<-function(x,xstar=0,quantile=.5,alternative="two.sided"){
  n<-length(x)
  p<-quantile
  T1<-sum(x<=xstar)
  T2<-sum(x< xstar)
  if (alternative=="quantile.less") {
    p.value<-1-pbinom(T2-1,n,p)}
  if (alternative=="quantile.greater"){
    p.value<-pbinom(T1,n,p)}
  if (alternative=="two.sided"){
    p.value<-2*min(1-pbinom(T2-1,n,p),pbinom(T1,n,p))}
  list(xstar=xstar,alternative=alternative,T1=T1,T2=T2,p.value=p.value)}

Confidence Interval

Data

The data consists of observations \(X_1, X_2, ..., X_n\) which are independent and identically distributed random variables. \(X^{(1)} \leq X^{(2)} \leq ... \leq X^{(r)} \leq ... \leq X^{(n)}\) represents the ordered sample, where \(1 \leq r < s \leq n\). We want to find the CI for an unknown \(p^*\)th quantile, where \(p^*\) is some specified number between 0 and 1.

Assumptions

  1. The sample \(X_1, X_2, ..., X_n\) is a random sample
  2. The measurement scale of the \(X_i\)s is at least ordinal

Approach

Approach A:

  • For \(n \leq 20\), Table A3 can be used to find \(s\) and \(r\). Specific instructions on finding \(s\) and \(r\) can be found on pg 143 of textbook.

Approach B:

  • For \(n > 20\), use the approximation based on the central limit theorem. Compute: \[ r^* = np^* -z_{\alpha/2} \sqrt{np^*(1-p^*)} \] and \[ s^* = np^* -z_{1-\alpha/2} \sqrt{np^*(1-p^*)} \]

where \(z_{1-\alpha/2}\) is obtained from Table A1. The confidence coefficient is approximately \(1-\alpha\).

One-sided confidence intervals are of the form: \[ P(X^{(r)} \leq x_{p^*}) = 1 - \alpha_1 \] and, if the distribution is continuous: \[ P(x_{p^*} \leq X^{(s)}) = 1 - \alpha_2 \] or, if not continous: \[ P(X^{(r)} \leq x_{p^*}) \geq 1 - \alpha_1 \] and \[ P(x_{p^*} \leq X^{(s)}) \geq 1 - \alpha_2 \]

Completed Homework Problem

A good example for the quantile test is found here: https://people.stat.sc.edu/hitchcock/notes518fall13sec32filledin.pdf

  1. The sergeant recalls that in the “good old days” the upper quartile for time required to complete the obstacle course was 42 minutes. He suspects that the new recruits are not as fit as the recruits in the good old days, so he times them on the obstacle course. He finds that out of 38 recruits, only ten of them complete the course within the 42 minute time period. Use the quantile test to test the hypothesis that the upper quartile is 42 minutes against the appropriate one-sided alternative.
#make a fake data set just to be able to use this function
x <- c(rep(42,10), rep(43,28))

quantile.test(x, xstar=42, quantile=0.75, alternative="quantile.greater")
$xstar
[1] 42

$alternative
[1] "quantile.greater"

$T1
[1] 10

$T2
[1] 0

$p.value
[1] 4.165498e-10

Hypotheses

  • \(H_0:\) \(P(X \leq x^*) \geq p^*\), where \(x^* = 42\) and \(p^* = 0.75\) for the upper quartile
  • \(H_1:\) \(P(X \leq x^*) < p^*\)

Test Statistic and p-Value

  • \(T_1 = 10\)
  • \(T_2 = 0\)
  • \(p = 4.165498e-10\)

Rejection Region

  • Reject \(H_0\) if \(p < \alpha\); \(\alpha=0.05\).

Conclusion/Interpretation

  • Reject \(H_0\).

  • There is sufficient evidence to suggest that the upper quartile of completion time for the obstacle course is greater than 42 minutes.
